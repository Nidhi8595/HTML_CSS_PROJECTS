# 🚀 Neelakshi's Portfolio

A modern, interactive, and responsive developer portfolio built with **HTML**, **CSS**, and **JavaScript**.

## ✨ Features

- **Sleek Glassmorphism UI** with animated cards and SVG hero wave
- **Categorized Skills** with logos and interactive highlighting—see which projects/certifications use each skill!
- **Project & Certification Showcase** with dynamic filtering and animated highlights
- **Dark Mode** toggle for a comfortable viewing experience
- **Responsive Design** for all devices
- **Smooth Animations** and scroll effects for a professional feel

## 🛠️ How It Works

- **Click any skill** to instantly highlight all related projects and certifications.
- **Hover over cards** for subtle animations and more info.
- **Dark mode** and mobile navigation included out of the box.

## 📂 Structure

- `index.html` — Main portfolio page
- `index.css` — All styles and animations
- `main.js` — Interactivity, skill/project linking, and effects
- `/logos/` — Skill and tool icons
